## Цель
научиться описывать запись объекта обязательной структурой struct, хранить коллекцию записей и обрабатывать её функциями. Читать и проверять данные текстового файла, выполнять запросы и сохранять одинаковый отчёт на экране и в файле. Диагностировать ошибки чтения и записи.

## Описание
Программа считывает сведения о провайдерах города из текстового файла, проверяет корректность каждой строки и выполняет обработку данных:
- отбирает провайдеров, предоставляющих услуги по заданному способу соединения;
- вычисляет для каждого отобранного провайдера стоимость передачи 1 МБ данных;
- определяет среди всех записей провайдера с самой высокой скоростью соединения и провайдера с самой низкой стоимостью передачи 1 МБ;
- формирует единый отчёт и выводит его одновременно в консоль и в текстовый файл.

## Исходные данные
При запуске программа последовательно запрашивает:
- Имя входного файла.
- Имя выходного файла.
- Способ соединения для фильтрации.

## Ожидаемый результат
Программа выводит одинаковый отчёт на экран и в указанный выходной файл:
- список провайдеров с заданным типом соединения (название, телефон, скорость, стоимость часа и рассчитанная стоимость 1 МБ) или EMPTY, если совпадений нет;
- провайдер с наибольшей скоростью соединения (или NONE, если файл пустой);
- провайдер с наименьшей стоимостью передачи 1 МБ (или NONE, если файл пустой).
